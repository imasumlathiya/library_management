# 📚 Library Management System

A simple **Python-based Library Management System** that allows users to add, view, search, issue, and return books. The system also saves book records in a text file so that data is available when the program is run again.

## ✨ Features

* ➕ Add new books
* 📖 Display all books
* 🔍 Search books by ID
* 📤 Issue books
* 📥 Return books
* 💾 Save and load book records
* 📝 File handling using `library.txt`
* 🖥️ Simple menu-driven interface

## 🛠️ Technologies Used

* **Python**
* **Lists**
* **Dictionaries**
* **Functions**
* **Loops**
* **Conditional Statements**
* **File Handling**

## ▶️ How to Run

1. Make sure Python is installed.
2. Open the project in VS Code or any Python IDE.
3. Run the Python file:

```bash
python library_management.py
```

4. Select an option from the menu.

## 📋 Menu Options

```text
1. Add Book
2. Display Books
3. Search Book
4. Issue Book
5. Return Book
6. Exit
```

## 💾 Data Storage

Book details are stored in `library.txt`. The program automatically loads previously saved books when it starts and saves the current book records when you choose **Exit**.

## 🎯 Purpose

This project was created to practice **Python programming concepts such as functions, lists, dictionaries, loops, conditions, and file handling** through a simple real-world application.
